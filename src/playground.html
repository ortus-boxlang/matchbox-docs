01 / A REAL SESSION

Write. Run. Repeat.

The editor and REPL share variables, functions, and objects. Clear only removes output; Reset session creates a fresh VM. Choosing another demo also resets the session.

02 / YOUR BROWSER, YOUR CODE

Local by design.

Code is compiled and executed on your device, not sent to a server. Output appears when a run finishes. Copy work you want to keep: edits and sessions aren’t saved on reload.

03 / ROOM TO EXPERIMENT

Small, on purpose.

Runs stop after 5 seconds, with 128 MiB of WASM memory and 64 KiB source/output limits. Stop or a runtime trap resets the VM. Files, network, DOM, JVM APIs, native clocks, and async/timers aren’t supported here. See target differences →
