Native MatchBox includes http() when built with bif-http, which is enabled by default. Requests run in-process and return futures; no curl executable is required.

Make a request

response = jsonDeserialize(http({
    url: "https://example.com/",
    timeout: 10
}).get());

println(response.status);
if (response.status == 200) {
    println(response.body);
}

.get() waits for completion. Its result is JSON text describing the response. For a JSON API, deserialize response.body separately to obtain the API payload. HTTP 4xx and 5xx responses are returned normally; always inspect the status.

Response fields

FieldMeaning
statusNumeric HTTP status code.
bodyResponse text when not downloading to a file.
file_contentThe same response text as body.
file_pathDownload destination when using path.

Request options

OptionDefaultBehavior
urlRequiredHTTP or HTTPS address.
methodGETGET, POST, PUT, or DELETE; case-insensitive.
headersNoneA struct of header names and values.
bodyNoneRequest text. Serialize JSON explicitly.
pathNoneDownload into a file instead of returning body text.
timeout30Total deadline in seconds, including redirects and body reads. Zero disables it.
connectionTimeout0Connection deadline in seconds, including DNS, TCP, and TLS. Zero means no separate deadline.
redirecttrueFollow up to 10 redirects.
noProxyfalseBypass system/environment proxies for this request.
ipv4OnlyfalseRestrict this machine's outgoing connection to IPv4.

Keys are case-insensitive. Deadlines must be finite, non-negative numbers and may be fractional. Boolean controls require actual booleans, not strings or numbers. Explicit null is invalid for these controls; omit the key to use its default.

The total deadline is not an inactivity timeout: receiving data does not reset it. With a proxy, ipv4Only affects your connection to the proxy, not the proxy's upstream connection.

Handle failures

try {
    response = jsonDeserialize(http({
        url: "https://example.com/",
        timeout: 5,
        connectionTimeout: 2,
        redirect: false
    }).get());
    println("HTTP status: " & response.status);
} catch (any error) {
    println("Request failed: " & error.message);
}

Invalid options throw before a request starts. Transport, timeout, and file failures reject the future and throw when .get() is called. TLS certificate verification remains enabled. Do not log credentials, request headers, or sensitive bodies.

Download safely

response = jsonDeserialize(http({
    url: "https://example.com/archive.zip",
    path: "archive.zip.tmp",
    timeout: 60
}).get());

The destination can be overwritten once headers arrive, and an interrupted download can leave a partial file. Download to a temporary path, verify the status and expected checksum, then move the file into place.

Runtime compatibility

This is the native MatchBox request-struct API, not the JVM runtime's fluent HTTP client. Successful HTTP future completion is not implemented for WASM/browser builds. These examples and request controls do not add browser HTTP support.
