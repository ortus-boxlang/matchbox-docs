First, install the MatchBox CLI. This walkthrough uses a terminal and a single file.

1. Write a script

Create hello.bxs:

function greet(name) {
    return "Hello, #name#!";
}

println(greet("world"));

.bxs is the BoxLang script extension. The expression between # characters is interpolated into the string.

2. Run it

matchbox hello.bxs

MatchBox parses, compiles, and executes the file. The expected output is:

Hello, world!

3. Make it standalone

matchbox --target native hello.bxs
./hello

On Windows, run .\hello.exe. Share the resulting executable with someone on the matching OS and architecture: they do not need MatchBox or Java installed. The VM is included in the executable; this is not a translation of every BoxLang operation into machine code.

Compile to bytecode instead

matchbox --build hello.bxs
matchbox hello.bxb

A .bxb file contains precompiled bytecode, not a standalone runtime. Its destination still needs a compatible MatchBox runner. Keep compiler and runtime versions aligned.

To omit embedded source text from the artifact:

matchbox --build --strip-source hello.bxs

Errors still retain file and line information. Removing source reduces diagnostic context; it is not an encryption or intellectual-property protection mechanism.

Try the REPL

Run matchbox without a filename, then experiment interactively:

numbers = [1, 2, 3];
println(arrayMap(numbers, (n) => n * 2));
