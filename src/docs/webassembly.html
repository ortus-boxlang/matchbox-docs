Browser WASM and server-side WASI are different targets.

Use --target js for the browser integration below. For Wasmtime or WASI workloads, use the WASI guide, not the browser artifact.

Export BoxLang functions

Create greetings.bxs:

function greet(name) {
    return "Hello, " & name & "!";
}

function multiply(a, b) {
    return a * b;
}

Top-level functions become exports in the generated ES module. Do not treat BoxLang access modifiers as a browser security boundary; the generated module exposes top-level functions.

Compile an ES module

matchbox --target js greetings.bxs

The browser package includes greetings.js and greetings.wasm. Keep generated companion files together. Packaging may require wasm-bindgen-cli matching the compiler's wasm-bindgen version; the reviewed repository pins 0.2.114.

Use it in HTML

<!doctype html>
<html lang="en">
<head><meta charset="utf-8"><title>Hello MatchBox</title></head>
<body>
  <p id="greeting">Loading…</p>
  <script type="module">
    import { greet } from './greetings.js';
    document.getElementById('greeting').textContent = await greet('browser');
  </script>
</body>
</html>

Importing the module initializes the runtime automatically. The browser contract also exposes window.MatchBox.modules["greetings"], window.MatchBox.ready("greetings"), and a framework-agnostic MatchBox.State() helper for state-snapshot applications.

Access browser APIs

js.document.getElementById("greeting").innerText = "Updated by BoxLang";
js.console.log("Hello from the browser");

Plain JavaScript values cross the boundary as BoxLang values. Browser objects such as DOM nodes, functions, and window remain JavaScript handles. The js bridge is browser-only, not a native CLI API.

Serve and deploy

python3 -m http.server 8080

Open http://localhost:8080. Do not open the page directly with file://; browsers restrict module and WASM loading. Deploy the HTML and generated files to a static host that serves .wasm with Content-Type: application/wasm.

Other WASM modes

  • --target wasm produces raw browser-oriented WASM. You supply the loader and required imports; it is not a drop-in WASI command.
  • A source-built runtime package exposes run_boxlang() to execute source strings and BoxLangVM for persistent instances.

The generated JS wrapper is browser-focused. Node.js, edge-worker globals, filesystem access, and native HTTP future completion are not interchangeable with a browser host. Validate those environments separately rather than assuming compatibility.
