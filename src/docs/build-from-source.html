Requirements

Use a recent stable Rust toolchain supporting the 2024 edition and the repository's dependencies, plus a platform C linker. Rust 1.85 introduced the edition, but dependency versions may require newer Rust.

The build orchestrates runner stubs as well as the CLI. Install the WASI target used by the standard runner path:

rustup target add wasm32-wasip1

Clone and build

git clone https://github.com/ortus-boxlang/matchbox.git
cd matchbox
cargo build --release
./target/release/matchbox --version

Use target\release\matchbox.exe on Windows. Add the containing directory to PATH if you want to invoke matchbox from elsewhere. Pin a tag or commit for repeatable builds.

Feature selection

FeaturePurpose
jitNative Cranelift JIT.
serverBuilt-in web server support.
cross-compileBuild/embed additional target stubs; needs the corresponding toolchains.
bif-ioFilesystem functions.
bif-httpNative HTTP requests.
bif-cryptoCryptographic functions.
bif-cliTerminal utilities.
bif-jniExperimental native Java interoperability.
bif-zipZIP support.
bif-datasourceDatasource functionality.
qoqQuery-of-Queries compiler and VM support.

Consult Cargo.toml for exact defaults. Cargo features are additive, and workspace dependencies can enable features of their own.

cargo build --release --features cross-compile

cargo build --release --no-default-features --features bif-io,bif-http

Build the separate server

cargo build --release -p matchbox_server
./target/release/matchbox_server --help

The Cargo binary uses matchbox_server; downloaded server distributions may use matchbox-server.

Target-specific tooling

  • Browser WASM: add wasm32-unknown-unknown and install wasm-bindgen-cli matching the workspace crate version (currently pinned to 0.2.114 in the reviewed checkout).
  • WASI HTTP: add wasm32-wasip2.
  • ESP32: prepare the Espressif toolchain and activate ESP-IDF as described in the embedded guide.
rustup target add wasm32-unknown-unknown wasm32-wasip2
cargo install wasm-bindgen-cli --version 0.2.114

Older instructions mention a js Cargo feature. It is not present in the reviewed root manifest; do not copy that flag into current builds.

Validate your checkout

cargo test
cargo clippy
cargo test --test boxlang_compat_tests

See the repository's contributor instructions for target-specific tests. Cross builds need an appropriate linker and libraries in addition to the Rust target.
