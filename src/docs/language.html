MatchBox implements a growing subset of BoxLang. These examples introduce the core language; consult compatibility before bringing over a JVM application.

Variables & strings

name = "MatchBox";
active = true;
versionCount = 3;
println("Hello, #name#!");
println("Built with " & name);

Variables are dynamically typed. Use & for string concatenation and #expression# for interpolation. Inside a quoted string, double the quote delimiter to include it literally. Backslashes remain literal.

Arrays & structs

targets = ["native", "browser", "embedded"];
println(targets[1]); // native: arrays are 1-indexed
arrayAppend(targets, "wasi");

project = { name: "Hello", ready: true };
println(project.NAME); // struct keys are case-insensitive

lengths = arrayMap(targets, (target) => len(target));

Control flow

for (target in targets) {
    if (target == "native") {
        println("Build an executable");
    } else {
        println("Explore " & target);
    }
}

for (i = 1; i <= 3; i++) {
    println(i);
}

Other supported constructs include while, switch, break, continue, and conditional expressions.

Functions & closures

function greet(name = "world") {
    var greeting = "Hello, " & name;
    return greeting;
}

double = (n) => n * 2;
println(greet());
println(double(21));

Functions can have default arguments and type hints. Use var for function-local variables. Functions can be passed as values and can capture surrounding state.

Classes & interfaces

class Product accessors="true" {
    property name;
    property price;
}

product = new Product();
product.setName("Widget");
product.setPrice(9.99);
println(product.getName());

MatchBox supports inheritance, interfaces, default interface methods, and onMissingMethod. For multi-file projects, use the repository examples and test class resolution in your target build.

Asynchronous work

future = runAsync(() => {
    sleep(100);
    return "done";
});

println(future.get());

The VM schedules work using cooperative fibers. sleep() accepts milliseconds; native HTTP request deadlines use seconds. Do not assume fibers behave exactly like JVM threads or that every target supports the same asynchronous I/O.

Handle failures

try {
    throw "Something went wrong";
} catch (any error) {
    println(error.message);
} finally {
    println("Finished");
}

For the broader language, see the BoxLang reference. JVM-specific APIs are not automatically available in MatchBox.
