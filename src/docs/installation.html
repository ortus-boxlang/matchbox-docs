Quick install

The official installer offers a release or snapshot and installs the Fat CLI, including embedded runners for deployment targets. Running ordinary BoxLang code does not require a JVM.

Linux / macOS

curl -sSL https://raw.githubusercontent.com/ortus-boxlang/matchbox/master/install/install.sh | bash

Windows PowerShell

iex (Invoke-RestMethod -Uri https://raw.githubusercontent.com/ortus-boxlang/matchbox/master/install/install.ps1)

These commands download and execute a script. You can inspect the shell installer or PowerShell installer first, or use a release archive instead. Follow the installer's PATH instructions and open a new terminal if necessary.

Verify your installation

matchbox --version
matchbox --help
matchbox

The last command opens the interactive REPL. Try:

println("Hello from MatchBox!");

Press Ctrl + D to leave the REPL.

Release archives

Download an archive matching your operating system and architecture from GitHub Releases. Extract it and place the executable on your PATH. On Linux and macOS, make sure the file is executable with chmod +x matchbox.

Use a pinned release for repeatable builds. Snapshots include newer changes but may have different capabilities from the stable release.

Use Docker instead

docker pull ghcr.io/ortus-boxlang/matchbox:latest
docker run --rm -v "$PWD:/app" ghcr.io/ortus-boxlang/matchbox:latest --help

The volume example uses a Unix-style shell. In other shells, replace $PWD with the absolute path to your project. See the Docker guide for builds and web serving.

Do I need Rust?

Not to run the prebuilt CLI or ordinary standalone applications. You do need Rust to build MatchBox from source or compile Native Fusion code. Some targets need additional tools: browser packaging may need a matching wasm-bindgen-cli, and ESP32 requires its own Rust and ESP-IDF environment.
