01 / A REAL SESSION

Write. Run. Repeat.

The editor and the console share variables, functions and objects. Clear empties the editor and the console but keeps your variables. Reset session starts a fresh VM, and so does choosing another demo.

02 / YOUR BROWSER, YOUR CODE

Local by design.

Code is compiled and run on your device, not sent to a server. Edits and sessions are not saved when you reload, so copy anything you want to keep.

03 / ROOM TO EXPERIMENT

Small, on purpose.

Runs stop after 5 seconds, with 128 MiB of memory and 64 KiB limits on source and output. There are no files, network, DOM, JVM APIs or JIT here. See target differences →
