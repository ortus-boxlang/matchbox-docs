# Examples & resources

The MatchBox repository contains examples for CLI applications, native builds, browser modules, WASI containers, HTTP servers, Lambda, ESP32, and Rust interoperability.

::: cards
::: card title="Application server" icon="phosphor-duotone:globe" href="../examples/app_server/README.md"
Routes, middleware, request scopes, templates, and HTTP services.
:::
::: card title="Browser WebAssembly" icon="phosphor-duotone:browser" href="../examples/wasm_browser/README.md"
Compile BoxLang modules for a browser host.
:::
::: card title="WASM container" icon="phosphor-duotone:cube" href="../examples/wasm_container/README.md"
Explore server-side WebAssembly packaging and execution.
:::
::: card title="Native Fusion" icon="phosphor-duotone:cpu" href="../examples/native_fusion/README.md"
Connect BoxLang applications to Rust functions.
:::

The repository's [changelog](https://github.com/ortus-boxlang/matchbox/blob/development/CHANGELOG.md) and [compatibility notes](../differences-from-boxlang.md) are useful when evaluating a release.
